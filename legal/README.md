Marcadores comunes: `[TITULAR]` nombre o razón social, `[NIF]`, `[DOMICILIO]`, `[EMAIL_PRIVACIDAD]` (por defecto `soporte@autoqr.com`), `[FECHA]`, `[VERSION]`.

Al publicar una versión nueva de términos o privacidad, incrementar `[VERSION]` y desplegar el cambio para que el sistema vuelva a pedir la aceptación.
